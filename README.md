# Redirect to Notes

**Description**: A modern, mobile-friendly redirect page that automatically forwards visitors to the new website address.

## Overview
This project serves as a transitional landing page for `pietrodefinis.com` (or the previous URL), informing users that the site has moved and redirecting them to the new location.

## Key Features
- **Automatic Redirection**: Scripts automatically redirect users after a 5-second countdown.
- **Modern UI**: Styled with clean CSS, gradients, and a card-based layout.
- **Responsive**: Optimized for both mobile and desktop viewports.
- **Localized**: Content is presented in Italian.
